# Adaptateur UniRig

Répertoire réservé, sans moteur opérationnel. Un futur adaptateur convertira les données d’un maillage vers le format UniRig, puis retournera le squelette et/ou les poids dans le format d’échange du projet. L’environnement Python et les poids resteront externes à Blender. Voir [l’étude](../../docs/etude-backends.md).
